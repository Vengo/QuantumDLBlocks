## 1. Executive Summary & Project Context

### 1.1. What This Project Is Trying to Achieve
In the `QuantumDLBlocks` project, we are investigating whether deep autoregressive language models can be built and trained end-to-end using principles from **quantum statistical mechanics** and **Riemannian differential geometry** rather than standard Euclidean linear algebra and heuristic exponential softmax layers.

Specifically, instead of representing each attention head's context as a single flat real vector aggregated by exponential `softmax(Q K^T / sqrt(d))` and updating unconstrained weight matrices in Euclidean space $\mathbb{R}^{m \times n}$, our architecture (**[`ModularQuantumStatMechGPT`](file:///home/nixos/QuantumDLBlocks/src/qdlblocks/models/modular_quantum_statmech_gpt.py#L562)**, `12` layers, model dimension $d_{\text{model}} = 768$, $H = 6$ heads, **`159.29M` parameters**):
1. **Replaces Exponential Softmax Attention with Algebraic $p$-Boson Born-Rule Coincidence**: Computes causal attention weights purely from the 6th power of complex query-key inner product magnitudes, $S_{t,s} = \mathbf{1}_{s \le t}\,|\langle q_t \mid k_s \rangle|^6$, normalized by their causal sum $w_{t,s} = S_{t,s} / (\sum_{u \le t} S_{t,u} + \epsilon)$ ($\epsilon = 10^{-6}$), with **zero `exp()` or `softmax()` calls** in the attention mechanism.
2. **Transports Mixed Quantum Density Matrices ($\rho \in \mathbb{C}^{16 \times 16}$) Across Context**: Each token $s$ maps its value projection into $R = 4$ complex wavepacket branches $\Psi_s \in \mathbb{C}^{4 \times 16}$ per head and forms a trace-1, positive semi-definite (PSD) Hermitian density matrix $\rho_s^{\text{tok}} = \tilde{\Psi}_s^\dagger \tilde{\Psi}_s \in \mathbb{C}^{16 \times 16}$ ($\operatorname{Tr}(\rho_s^{\text{tok}}) = 1$). Causal attention aggregates these token density matrices into a mixed contextual density state $\rho_t^{(0)} = \sum_{s \le t} w_{t,s}\,\rho_s^{\text{tok}}$ whose von Neumann / Tsallis entropy quantifies contextual uncertainty across superposed tokens.
3. **Applies Thermodynamic Density Purification, Quantum Channel Evolution, and Uhlmann Phase-Locked Krylov Extraction**: Each head purifies $\rho_t^{(0)}$ via nonlinear spectral polynomials (such as McWeeny Bures-Wasserstein $\rho^2 / \operatorname{Tr}(\rho^2)$ or cubic Fermi-Dirac $3\rho^2 - 2\rho^3$), evolves the density matrix through either a closed unitary operator $U_h \in U(16)$ or an open Completely Positive Trace-Preserving (CPTP) Rank-$K$ Kraus channel $\mathcal{E}_h(\rho) = \sum_{k=1}^K A_{h,k}\rho A_{h,k}^\dagger$, and extracts the top-2 dominant eigenmodes via a 2-step Lanczos-Krylov recursion gauge-locked by Uhlmann parallel-transport phase.
4. **Constrains Every Weight Matrix to a Compact Riemannian Manifold**:
   - All `85` real projection matrices (`1` input rotation `w_in_stiefel` + $12 \times 7$ per-layer matrices `w_q`, `w_k`, `w_v`, `w_obs`, `w_beam_a`, `w_beam_b`, `w_chan`) live on **real Stiefel manifolds** $\mathrm{St}(D, d) = \{W \in \mathbb{R}^{D \times d} : W^\top W = I_d\}$ ($D \ge d$): **`37` square orthogonal matrices** in $O(768) = \mathrm{St}(768, 768)$ (`w_in_stiefel` and $12 \times 3$ matrices `w_q, w_k, w_v`) and **`48` rectangular semi-orthogonal matrices** ($12 \times$ `w_obs` in $\mathrm{St}(1920, 768)$ and $12 \times 3$ matrices `w_beam_a, w_beam_b, w_chan` in $\mathrm{St}(1536, 768)$).
   - All `12` per-layer multi-head quantum evolution operators (`head_unitary_re`, `head_unitary_im`) live on the **complex unitary group** $U(16)^6$ (`UNITARY_U16`) or **complex Stiefel Kraus manifold** $\mathrm{St}_{\mathbb{C}}(64, 16)^6$ (`CPTP_KRAUS_RANK_K`).
   - Both vocabulary matrices (`wte.weight` and `lm_head.weight`, each $50,304 \times 768$) live on the **unit-RMS hypersphere product manifold** $(\sqrt{768}\,\mathbb{S}^{767})^{50,304}$ (every token vector has Euclidean L2 norm $\sqrt{768}$, i.e., root-mean-square coordinate magnitude $1.0$).

### 2.3. Layer-by-Layer Forward Pass of `ModularQuantumStatMechGPT` ($L=12, d_{\text{model}}=768, H=6, d_h=16, R=4$)

Given a batch of input token indices $\text{idx} \in \{0, \dots, 50303\}^{B \times T}$:

1. **Sphere-Constrained Token Embedding & Stiefel Input Rotation**:
   - Each row $e_v \in \mathbb{R}^{768}$ of `wte.weight` lives on the unit-RMS sphere $\sqrt{768}\,\mathbb{S}^{767}$ ($\|e_v\|_2 = \sqrt{768}$).
   - Input embeddings $E = \mathrm{wte}(\text{idx}) \in \mathbb{R}^{B \times T \times 768}$ are cast to `bfloat16`, RMS-normalized per token ($\mathrm{RMSNorm}(x) = x / \sqrt{\frac{1}{768}\sum_{i=1}^{768} x_i^2 + \epsilon_{\text{rms}}}$ with $\epsilon_{\text{rms}} = 10^{-6}$), and multiplied by $W_{\text{in}} \in O(768)$ and scalar gain $\alpha_{\text{in}} \in [0.5, 2.0]$ (`in_scale`, initialized to `1.0`):
     $$X^{(0)} = \alpha_{\text{in}}\,\mathrm{RMSNorm}(E)\,W_{\text{in}} \in \mathbb{R}^{B \times T \times 768}$$
   - We also store $X_{\text{anchor}} = X^{(0)}$ as the global residual-highway anchor across all 12 layers.

2. **Per-Block Residual Highway ($\lambda_{\text{block}}^{(\ell)}$), Value Highway ($\lambda_v^{(\ell)}$), and Complex Reshaping**:
   - At layer $\ell \in \{0, \dots, 11\}$ ([`ModularQuantumStatMechBlock`](file:///home/nixos/QuantumDLBlocks/src/qdlblocks/models/modular_quantum_statmech_gpt.py#L125)), the hidden state $X^{(\ell)}$ is mixed with $X^{(0)}$ via learnable 2-vector $\lambda_{\text{block}}^{(\ell)} = [\lambda_{\text{block},0}^{(\ell)}, \lambda_{\text{block},1}^{(\ell)}]$ (initialized to $[1.0, 0.0]$):
     $$X_{\text{cur}}^{(\ell)} = \lambda_{\text{block},0}^{(\ell)}\,X^{(\ell)} + \lambda_{\text{block},1}^{(\ell)}\,X^{(0)}, \qquad H_{\text{norm}}^{(\ell)} = \mathrm{RMSNorm}\!\big(X_{\text{cur}}^{(\ell)}\big)$$
   - Three square orthogonal Stiefel matrices $W_q^{(\ell)}, W_k^{(\ell)}, W_v^{(\ell)} \in O(768)$ project $H_{\text{norm}}^{(\ell)} \in \mathbb{R}^{B \times T \times 768}$ into $H = 6$ heads ($128$ real coordinates per head).
   - **Complex Query/Key Reshaping ($\mathbb{R}^{768} \to (\mathbb{C}^{64})^6$)**: `q_raw = (h_norm @ w_q).view(B, T, 6, 2, 64)` splits each head's $128$ real outputs into a $64$-dimensional real part `q_re = q_raw[..., 0, :]` and a $64$-dimensional imaginary part `q_im = q_raw[..., 1, :]` (and identically for `k_re, k_im`).
   - **Value Highway & Multi-Branch Wavepacket Reshaping ($\mathbb{R}^{768} \to (\mathbb{C}^{4 \times 16})^6$)**: In Layer $0$, $V_{\text{proj}}^{(0)} = H_{\text{norm}}^{(0)} W_v^{(0)}$ defines the initial value anchor $V^{(0)} = V_{\text{proj}}^{(0)}$ (`v_mixed = V^{(0)}`). In Layers $\ell \ge 1$, $V_{\text{proj}}^{(\ell)} = H_{\text{norm}}^{(\ell)} W_v^{(\ell)}$ is blended with $V^{(0)}$ via $\lambda_v^{(\ell)} = [\lambda_{v,0}^{(\ell)}, \lambda_{v,1}^{(\ell)}]$ (initialized to $[1.0, 0.15]$):
     $$V_{\text{mixed}}^{(\ell)} = \lambda_{v,0}^{(\ell)}\,V_{\text{proj}}^{(\ell)} + \lambda_{v,1}^{(\ell)}\,V^{(0)}$$
     Reshaping `v_raw = v_mixed.view(B, T, 6, 4, 2, 16)` yields $R=4$ complex 16-dimensional wavepacket branches per head (`v_re = v_raw[..., 0, :]`, `v_im = v_raw[..., 1, :]`), stacked as rows of $\Psi_{b,h,s} \in \mathbb{C}^{4 \times 16}$.
   - **Complex L2 Normalization, RoPE, and Partial Key Offset**: Queries $q_{b,h,t} \in \mathbb{C}^{64}$ and keys $k_{b,h,s} \in \mathbb{C}^{64}$ are first L2-normalized to unit length ($\|q_{b,h,t}\|_2 = \|k_{b,h,s}\|_2 = 1$ with $\epsilon = 10^{-6}$) and rotated by complex Rotary Position Embeddings $q_{t,j} \mapsto q_{t,j} e^{i t \omega_j}$ ($\omega_j = 10000^{-j/64}$ for $j \in \{0, \dots, 63\}$). On long-window layers $\ell \in \{3, 7, 11\}$, the block calls [`apply_partial_key_offset`](file:///home/nixos/QuantumDLBlocks/src/qdlblocks/layers/isometric.py#L430) after RoPE (which shifts non-rotary key channels $[r_{\text{dim}}, d_{\text{head}})$ by one token $s-1 \to s$ with $s=0$ kept in-place; note that because `rotary_dim = 64` equals the full complex head dimension $64$, this call is currently a no-op identity unless `rotary_dim < 64`).

3. **Causal $p=3$ Boson Born-Rule Coincidence Weights**:
   - Using the 2-GEMM real-block identity $q_{\text{cat},t} = [\operatorname{Re} q_t, \operatorname{Im} q_t] \in \mathbb{R}^{128}$, $k_{\text{cat},s} = [\operatorname{Re} k_s, \operatorname{Im} k_s] \in \mathbb{R}^{128}$, and $k_{\text{skew},s} = [-\operatorname{Im} k_s, \operatorname{Re} k_s] \in \mathbb{R}^{128}$, we compute $\operatorname{ip}_{\text{re},t,s} = \operatorname{Re}\langle q_t \mid k_s\rangle$ and $\operatorname{ip}_{\text{im},t,s} = -\operatorname{Im}\langle q_t \mid k_s\rangle$ in two `bfloat16` matrix multiplications.
   - The 3-boson ($p=3$) causal Born coincidence probability ([`causal_born_p3_weights`](file:///home/nixos/QuantumDLBlocks/src/qdlblocks/layers/quantum_statmech_channels.py#L88-L112), with $\epsilon = 10^{-6}$) is:
     $$S_{t,s} = \mathbf{1}_{s \le t}\left(\operatorname{ip}_{\text{re},t,s}^2 + \operatorname{ip}_{\text{im},t,s}^2\right)^3 = \mathbf{1}_{s \le t}\,\left|\langle q_t \mid k_s\rangle\right|^6, \qquad w_{t,s} = \frac{S_{t,s}}{\sum_{u \le t} S_{t,u} + 10^{-6}}$$

4. **Isometric Density-Matrix Packing (`416` Dims/Head) & Contextual Superposition**:
   - Each token $s$ normalizes $\tilde{\Psi}_s = \Psi_s / \sqrt{\|\Psi_s\|_F^2 + 10^{-6}}$ so its outer product forms a trace-1, rank-4 PSD Hermitian density matrix on $\mathbb{C}^{16 \times 16}$:
     $$\rho_s^{\text{tok}} = \tilde{\Psi}_s^\dagger \tilde{\Psi}_s = \frac{\sum_{r=1}^4 |\psi_{s,r}\rangle\langle \psi_{s,r}|}{\sum_{r=1}^4 \||\psi_{s,r}\rangle\|_2^2 + 10^{-6}} \in \mathbb{C}^{16 \times 16}, \qquad \operatorname{Tr}(\rho_s^{\text{tok}}) = 1$$
   - Because any Hermitian matrix $\rho \in \mathbb{C}^{16 \times 16}$ has $16$ real diagonal entries, $120$ strictly upper-triangular real parts, and $120$ strictly lower-triangular imaginary parts ($16 + 120 + 120 = 256$), we define the **$\sqrt{2}$-isometric packing map** $\tilde{P} : \mathrm{Herm}(16) \to \mathbb{R}^{256}$ (where coordinate indices $0 \dots 15$ store the diagonal $\operatorname{Re}(\rho_{i,i})$, indices $16 \dots 135$ store $\sqrt{2}\operatorname{Re}(\rho_{i,j})$ for $i < j$, and indices $136 \dots 255$ store $-\sqrt{2}\operatorname{Im}(\rho_{i,j})$ for $i > j$):
     $$\tilde{P}(\rho)_{i,j} = \begin{cases} \operatorname{Re}(\rho_{i,i}) & \text{if } i = j \\ \sqrt{2}\operatorname{Re}(\rho_{i,j}) & \text{if } i < j \\ -\sqrt{2}\operatorname{Im}(\rho_{i,j}) & \text{if } i > j \end{cases}$$
     which is an exact Euclidean-to-Hilbert-Schmidt isometry: for any two Hermitian matrices $A, B \in \mathrm{Herm}(16)$,
     $$\big\langle \tilde{P}(A),\; \tilde{P}(B) \big\rangle_{\mathbb{R}^{256}} = \operatorname{Tr}(A B), \qquad \big\|\tilde{P}(\rho)\big\|_2^2 = \operatorname{Tr}(\rho^2) = \mathcal{P}(\rho)$$
   - Each token packs $\tilde{P}(\rho_s^{\text{tok}}) \in \mathbb{R}^{256}$, the unit-norm coherent mean ket $|\hat{v}_s^{\text{coh}}\rangle = \frac{\sum_{r=1}^4 |\psi_{s,r}\rangle}{\|\sum_{r=1}^4 |\psi_{s,r}\rangle\|_2} \in \mathbb{C}^{16} \cong \mathbb{R}^{32}$, and all 4 raw complex wavepacket branches $\{|\psi_{s,r}\rangle\}_{r=1}^4 \in \mathbb{C}^{4 \times 16} \cong \mathbb{R}^{128}$ into a single `416`-dim vector per head ($256 + 32 + 128 = 416$) and contracts them with $w_{t,s}$ in a single causal GEMM:
     $$\rho_t^{(0)} = \sum_{s \le t} w_{t,s}\,\rho_s^{\text{tok}}, \qquad |\bar{v}_t\rangle = \sum_{s \le t} w_{t,s}\,|\hat{v}_s^{\text{coh}}\rangle, \qquad |\bar{\psi}_{t,r}\rangle = \sum_{s \le t} w_{t,s}\,|\psi_{s,r}\rangle$$

5. **Thermodynamic Purification, Unitary/Kraus Evolution, Uhlmann Krylov Extraction, and `obs_320` Fusion**:
   - **Purification & Channel Evolution of $\rho_t^{(0)}$**: The contextual mixed state $\rho_t^{(0)}$ is purified to $\rho_t^{(1)}$ via one of three selectable `PurificationMode` polynomials (Section 3.5) and evolved to $\rho_{t,\text{out}}$ via either closed unitary conjugation $U_h \rho_t^{(1)} U_h^\dagger$ (`UNITARY_U16`, $U_h \in U(16)$) or an open Rank-$K$ CPTP Kraus channel $\sum_{k=1}^K A_{h,k} \rho_t^{(1)} A_{h,k}^\dagger$ (`CPTP_KRAUS_RANK_K`, $K=4$, $A_h \in \mathrm{St}_{\mathbb{C}}(64, 16)$, Section 3.3).
   - **Unitary vs. Kraus Evolution of Coherent Kets ([`statmech_purify_evolve_uhlmann_krylov_impl`](file:///home/nixos/QuantumDLBlocks/src/qdlblocks/layers/quantum_statmech_channels.py#L594-L637))**:
     - The coherent mean ket $|\bar{v}_t\rangle \in \mathbb{C}^{16}$ is evolved by the primary ($k=1$) operator block $A_{h,1} = \text{op}_{h, 0:16, 0:16} \in \mathbb{C}^{16 \times 16}$ (which equals $U_h$ in `UNITARY_U16` mode): $|\bar{v}_{t,U}\rangle = A_{h,1}|\bar{v}_t\rangle$.
     - For the $R=4$ wavepacket branches $|\bar{\psi}_{t,r}\rangle \in \mathbb{C}^{16}$ ($r \in \{1..4\}$), in `UNITARY_U16` mode all 4 branches are evolved by $U_h$ ($|\psi_{t,r,U}\rangle = U_h|\bar{\psi}_{t,r}\rangle$), whereas in `CPTP_KRAUS_RANK_K` mode with $K = R = 4$, each wavepacket branch $r$ is evolved by its corresponding $r$-th Kraus operator block $A_{h,r} \in \mathbb{C}^{16 \times 16}$: $|\psi_{t,r,U}\rangle = A_{h,r}|\bar{\psi}_{t,r}\rangle$!
   - **2-Step Uhlmann Phase-Locked Lanczos-Krylov Iteration ([`extract_rank2_krylov_eigenpair_uhlmann`](file:///home/nixos/QuantumDLBlocks/src/qdlblocks/layers/standalone_quantum_born_ops.py#L140-L202))**:
     To extract the top-2 dominant eigenmodes of $\rho_{t,\text{out}}$ without calling `torch.linalg.eigh` (whose backward pass blows up near degenerate eigenvalues and suffers from arbitrary $U(1)$ eigenvector phase flips):
     1. Normalize the anchor ket $|a\rangle = |\bar{v}_{t,U}\rangle / \sqrt{\langle\bar{v}_{t,U}\mid\bar{v}_{t,U}\rangle + \epsilon_{\text{Uhl}}^2}$ ($\epsilon_{\text{Uhl}} = 10^{-6}$).
     2. Apply one power step $|w_1\rangle = \rho_{t,\text{out}}|a\rangle$, normalize $|\tilde{\phi}_1\rangle = |w_1\rangle / \||w_1\rangle\|_2$, and **lock its $U(1)$ gauge phase** to $|a\rangle$ via the Uhlmann parallel-transport overlap $c_1 = \langle a \mid \tilde{\phi}_1\rangle = \sum_{j=1}^{16} a_j^* \tilde{\phi}_{1,j}$:
        $$|\phi_1\rangle = \frac{c_1^*}{\sqrt{|c_1|^2 + \epsilon_{\text{Uhl}}^2}}\,|\tilde{\phi}_1\rangle \implies \langle a \mid \phi_1\rangle = |c_1| \in \mathbb{R}_{\ge 0}$$
     3. Compute the first Rayleigh quotient $|r_1\rangle = \rho_{t,\text{out}}|\phi_1\rangle$ and $\lambda_1 = \operatorname{Re}\langle\phi_1 \mid r_1\rangle \in [0, 1]$.
     4. Orthogonalize the residual $|u_2\rangle = |r_1\rangle - \lambda_1|\phi_1\rangle$ against $|\phi_1\rangle$ via two-pass Gram-Schmidt ($|u_2^\perp\rangle = |u_2\rangle - \langle\phi_1\mid u_2\rangle|\phi_1\rangle$), normalize $|\tilde{\phi}_2\rangle = |u_2^\perp\rangle / \||u_2^\perp\rangle\|_2$, Uhlmann-phase-lock $|\phi_2\rangle = \frac{c_2^*}{\sqrt{|c_2|^2 + \epsilon_{\text{Uhl}}^2}}|\tilde{\phi}_2\rangle$ with $c_2 = \langle a \mid \tilde{\phi}_2\rangle$, and compute $\lambda_2 = \operatorname{Re}\langle\phi_2\mid\rho_{t,\text{out}}\mid\phi_2\rangle \in [0, 1]$.
   - **Explicit `obs_320` Fusion Equation ($256 + 128 + 64 \to 320$, [`quantum_statmech_channels.py`](file:///home/nixos/QuantumDLBlocks/src/qdlblocks/layers/quantum_statmech_channels.py#L639-L656))**:

     To combine these `448` coordinates ($256 + 128 + 64$) into a `320`-dim head observation vector $\text{obs}_{320,h} \in \mathbb{R}^{320}$, the `128`-dim linear wavepacket vector $\psi_{U,\text{flat}}$ is **superposed onto the first `128` coordinates** of $\text{packed\_rho}_{\text{out}} \in \mathbb{R}^{256}$ while keeping coordinates `128..255` of $\text{packed\_rho}_{\text{out}}$ unchanged, and then $\text{krylov}_{64} \in \mathbb{R}^{64}$ is concatenated ($256 + 64 = 320$):

   - **Observation Contraction & Two-Beam Mach-Zehnder Interference**:
     Concatenating $\text{obs}_{320,h}$ across all $H=6$ heads gives $\text{obs}_{\text{concat}} \in \mathbb{R}^{B \times T \times 1920}$, which contracts through the tall rectangular Stiefel matrix $W_{\text{obs}}^{(\ell)} \in \mathrm{St}(1920, 768)$ ($W_{\text{obs}}^{(\ell)\top} W_{\text{obs}}^{(\ell)} = I_{768}$) with scalar gain $\alpha_{\text{obs}}^{(\ell)} \in [0.02, 0.50]$ (initialized to `0.12`):
     $$X_{\text{mid}}^{(\ell)} = X_{\text{cur}}^{(\ell)} + \alpha_{\text{obs}}^{(\ell)}\,\text{obs}_{\text{concat}}\,W_{\text{obs}}^{(\ell)}$$
     Next, the two-beam Mach-Zehnder interferometer sublayer normalizes $M_{\text{norm}} = \mathrm{RMSNorm}(X_{\text{mid}}^{(\ell)}) \in \mathbb{R}^{B \times T \times 768}$, expands it isometrically into two `1,536`-dim beams via $a = M_{\text{norm}} W_{\text{beam},A}^{(\ell)}$ and $b = M_{\text{norm}} W_{\text{beam},B}^{(\ell)}$ (where $W_{\text{beam},A}^{(\ell)}, W_{\text{beam},B}^{(\ell)} \in \mathbb{R}^{768 \times 1536}$ have orthonormal rows $W_{\text{beam}} W_{\text{beam}}^\top = I_{768}$, i.e., $W_{\text{beam}}^\top \in \mathrm{St}(1536, 768)$), computes constructive minus destructive intensity interference $I_{\text{MZ}} = \mathrm{ReLU}(\frac{a+b}{\sqrt{2}})^2 - \frac{1}{4}\mathrm{ReLU}(\frac{a-b}{\sqrt{2}})^2 \in \mathbb{R}^{B \times T \times 1536}$, normalizes via `RMSNorm`, and contracts back through $W_{\text{chan}}^{(\ell)} \in \mathrm{St}(1536, 768)$ ($W_{\text{chan}}^{(\ell)\top} W_{\text{chan}}^{(\ell)} = I_{768}$) with scalar gain $\alpha_{\text{chan}}^{(\ell)}$ (`0.12`):
     $$X^{(\ell+1)} = X_{\text{mid}}^{(\ell)} + \alpha_{\text{chan}}^{(\ell)}\,\mathrm{RMSNorm}(I_{\text{MZ}})\,W_{\text{chan}}^{(\ell)}$$

6. **Final RMSNorm, Clamped Logit Scale ($s_{\text{eff}}$), and Vocabulary Readout (`SOFTCAP_LINEAR_CE` vs. `MEAN_CENTERED_ISOMETRIC_TRACE`)**:

### 3.2. Problem 2: Top-1 vs. Cross-Entropy Divergence & Mean-Centered Isometric Born Trace Readout
A central theoretical question from our reference PDF (*"Top-1 Accuracy vs Cross-Entropy Divergence"*) is why nonlinear quantum Born readouts of the form $z_{t,v} = \tau \log \operatorname{Tr}(\rho_t E_v)$ historically suffered from **Top-1 vs. Cross-Entropy Divergence**—achieving reasonable Top-1 accuracy while suffering a `0.3`–`0.8` nat penalty in validation Cross-Entropy (`Val CE`).

**Root Cause**:
1. When each vocabulary token $v \in \{0, \dots, V-1\}$ is represented by a positive semi-definite measurement effect $E_v \succeq 0$ with $\operatorname{Tr}(E_v) = 1$, all $V = 50,304$ operators lie in the positive octant cone and share a positive background mean operator $\bar{E} = \frac{1}{V}\sum_{v=0}^{V-1} E_v \approx \frac{1}{d_h} I_{d_h}$.
2. Consequently, every token's Born overlap $\operatorname{Tr}(\rho_t E_v) = \operatorname{Tr}(\rho_t \bar{E}) + \operatorname{Tr}(\rho_t (E_v - \bar{E}))$ is dominated by the constant background floor $\operatorname{Tr}(\rho_t \bar{E}) \approx 1/16$, compressing relative differences among runner-up tokens (ranks `2–5` and `6–50`) after taking $\log(\cdot)$.
3. In Wave 48's `RANK2_KRYLOV_BORN` readout ($I_{t,v} = \sum_{m=1}^2 \bar{\kappa}_{t,m}(1 + \frac{\langle h_{t,m}, w_{v,m}\rangle}{2\sqrt{384}})^2$), squaring the shifted inner product compresses negative alignments and distorts the logit tail distribution compared to a linear inner product.

**Our Solution — `MEAN_CENTERED_ISOMETRIC_TRACE` ([`MeanCenteredIsometricBornTraceCEFn`](file:///home/nixos/QuantumDLBlocks/src/qdlblocks/layers/isometric_born_trace_readout.py#L140))**:
- First, [`pack_multihead_wavepacket_density_isometric`](file:///home/nixos/QuantumDLBlocks/src/qdlblocks/layers/isometric_born_trace_readout.py#L46-L70) maps any vector $x \in \mathbb{R}^{768}$ into $H=6$ trace-1 rank-4 PSD Hermitian density matrices without any `RMSNorm` rescaling: it reshapes $x$ into `(H=6, R=4, 2, d_h=16)` complex wavepackets $\Psi_h(x) \in \mathbb{C}^{4 \times 16}$, Frobenius-normalizes each head $\tilde{\Psi}_h(x) = \Psi_h(x) / \sqrt{\|\Psi_h(x)\|_F^2 + 10^{-6}}$, forms the trace-1 rank-4 Hermitian density matrix $\rho_h(x) = \tilde{\Psi}_h(x)^\dagger \tilde{\Psi}_h(x) \in \mathrm{Herm}_+(16)$ ($\operatorname{Tr}(\rho_h(x)) = 1$), and packs all $H=6$ heads via the Hilbert-Schmidt isometry $\tilde{P}$ into $\tilde{P}(\rho(x)) \in \mathbb{R}^{6 \times 256} \cong \mathbb{R}^{1536}$.
- For each token $t$, [`ModularQuantumStatMechGPT.forward`](file:///home/nixos/QuantumDLBlocks/src/qdlblocks/models/modular_quantum_statmech_gpt.py#L448-L453) forms the effective multi-head contextual density packing $\tilde{P}(\rho_{\text{eff},t}) = \frac{1}{2}\tilde{P}(\rho_{t,\text{out}}^{(11)}) + \frac{1}{2}\tilde{P}(\rho(h_{\text{final},t})) \in \mathbb{R}^{1536}$ (combining the final layer's quantum channel output density with the density of the normalized final hidden state $h_{\text{final},t}$), and packs each vocabulary row $w_{\text{lm},v} \in \sqrt{768}\,\mathbb{S}^{767}$ into $\tilde{P}(E_v) = \tilde{P}(\rho(w_{\text{lm},v})) \in \mathbb{R}^{1536}$.
- Inside [`MeanCenteredIsometricBornTraceCEFn`](file:///home/nixos/QuantumDLBlocks/src/qdlblocks/layers/isometric_born_trace_readout.py#L152-L169), because $\tilde{P}$ is an exact Hilbert-Schmidt isometry, we compute the per-head-averaged quantum Born trace overlap $c_{\text{trace}}(t, v)$ and **subtract the vocabulary-wide mean overlap** across all $V = 50,304$ tokens (which by linearity of the trace is identically equivalent to replacing each measurement effect $E_{v,h}$ with the traceless, mean-centered observable $\mathring{E}_{v,h} = E_{v,h} - \frac{1}{V}\sum_{v'=0}^{V-1} E_{v',h}$):
  $$c_{\text{trace}}(t, v) = \frac{1}{H}\big\langle \tilde{P}(\rho_{\text{eff},t}),\; \tilde{P}(E_v)\big\rangle_{\mathbb{R}^{1536}} = \frac{1}{6}\sum_{h=1}^6 \operatorname{Tr}\!\big(\rho_{\text{eff},t,h}\,E_{v,h}\big)$$
  $$\tilde{c}_{\text{trace}}(t, v) = c_{\text{trace}}(t, v) - \frac{1}{V}\sum_{v'=0}^{V-1} c_{\text{trace}}(t, v') = \frac{1}{6}\sum_{h=1}^6 \operatorname{Tr}\!\Big(\rho_{\text{eff},t,h}\big(E_{v,h} - \bar{E}_h\big)\Big)$$
- Combining the first-order coherent inner product with this zero-mean second-order quantum trace yields:
  $$u_{t,v} = s_{\text{eff}}\,\langle h_{\text{final},t}, w_{\text{lm},v}\rangle + \beta_{\text{trace}}\,\tilde{c}_{\text{trace}}(t, v), \qquad z_{t,v} = 15.0\,\tanh\!\left(\frac{u_{t,v}}{15.0}\right)$$
  where $\beta_{\text{trace}} \in [0.25, 16.0]$ (`trace_beta`, initialized to `4.0`) is a learnable inverse-temperature coupling.
- To quantify readout calibration across the probability distribution, we built [`evaluate_readout_divergence_batch`](file:///home/nixos/QuantumDLBlocks/src/qdlblocks/layers/isometric_born_trace_readout.py#L289), which partitions validation tokens by the **predicted rank of the ground-truth target token** ($r_t \in \{1, \dots, V\}$, where $r_t = 1$ means Top-1 is correct) and reports the conditional Negative Log-Likelihood (`NLL`) within four rank buckets:
  - `nll_rank1`: Mean $-\log p(y_t \mid x_{\le t})$ when the ground-truth token is ranked `#1` (`Top-1` hit).
  - `nll_rank2_5`: Mean NLL when the ground-truth token is ranked `#2` through `#5` (near-miss runner-up tokens).
  - `nll_rank6_50`: Mean NLL when the ground-truth token is ranked `#6` through `#50`.
  - `nll_rank51_plus`: Mean NLL when the ground-truth token is ranked `#51` or worse (long tail).

### 3.3. Problem 3: Open-System CPTP Rank-$K$ Kraus Quantum Channels vs. Closed Unitary $U(16)$ Evolution
In closed-system quantum mechanics, unitary conjugation $\rho \mapsto U_h \rho U_h^\dagger$ ($U_h \in U(16)$) is isospectral: it rotates the eigenvectors of $\rho$ without changing its eigenvalues $\{\lambda_i\}_{i=1}^{16}$ or its entropy. Thus, in `UNITARY_U16` mode, a head cannot dynamically cool (purify) or heat (mix) a state based on which subspace $\rho$ occupies; all spectral sharpening comes from the fixed polynomial purification step.

**Our Formulation — `CPTP_KRAUS_RANK_K` ([`evolve_head_cptp_kraus_functional`](file:///home/nixos/QuantumDLBlocks/src/qdlblocks/layers/quantum_statmech_channels.py#L253-L274))**:
- By Stinespring's dilation theorem, the most general physically valid quantum evolution of an open system $\mathcal{H}_S = \mathbb{C}^{16}$ coupled to a $K$-dimensional environment $\mathcal{H}_E = \mathbb{C}^K$ ($K=4$) is a **Completely Positive Trace-Preserving (CPTP) Kraus channel**:
  $$\mathcal{E}_h(\rho) = \sum_{k=1}^K A_{h,k}\,\rho\,A_{h,k}^\dagger, \qquad \text{subject to the trace-preservation constraint } \sum_{k=1}^K A_{h,k}^\dagger A_{h,k} = I_{16}$$
- **Geometric Insight**: If we stack the $K=4$ Kraus operators $A_{h,1}, \dots, A_{h,4} \in \mathbb{C}^{16 \times 16}$ vertically into a single tall complex matrix
  $$A_h = \begin{bmatrix} A_{h,1} \\ \vdots \\ A_{h,K} \end{bmatrix} \in \mathbb{C}^{64 \times 16}$$
  then the CPTP trace-preservation constraint $\sum_{k=1}^K A_{h,k}^\dagger A_{h,k} = I_{16}$ is **identically equivalent** to the **complex Stiefel manifold constraint** $A_h^\dagger A_h = I_{16}$ ($A_h \in \mathrm{St}_{\mathbb{C}}(64, 16)$)!
- This allowed us to optimize all $K=4$ Kraus operators per head directly on $\mathrm{St}_{\mathbb{C}}(64, 16)$ using our complex Newton-Schulz Stiefel-Muon optimizer (`riemannian_complex_tangent_transport_muon_step`), initialized near a dominant unitary branch ($w_1^2 = 0.85$ on $k=1$ and $\frac{0.15}{3} = 0.05$ on $k=2,3,4$) so the channel starts near-unitary and learns dissipative attractor transitions where beneficial.
- **Engineering Lesson (6D Tensor Memory Trap & Post-Fix Performance)**: Our initial implementation reshaped $A_h$ into `(1, H, 1, K, 16, 16)` to evaluate all $K=4$ branches in parallel, which allocated 6D activation tensors `(B=8, H=6, T=1024, K=4, 16, 16)` across all 12 layers during backpropagation—consuming `24,287 MiB / 24,576 MiB` VRAM on a 24 GiB RTX 3090, triggering CUDA driver paging to system RAM, and throttling throughput to `1,062 tok/s`. Replacing the 6D broadcast with a 5D accumulation loop over `k_idx in range(4)` in [`evolve_head_cptp_kraus_functional`](file:///home/nixos/QuantumDLBlocks/src/qdlblocks/layers/quantum_statmech_channels.py#L264-L270) reduced peak training VRAM from `24.3 GiB` down to **`~11.4 GiB`** (`< 50%` of RTX 3090 VRAM) and restored compiled `CPTP_KRAUS_RANK_K` training throughput from `1,062 tok/s` to **`~9,800–10,500 tok/s` (~$9.5\times$ speedup)**.

### 3.4. Problem 4: Token Embedding Trainability (`wte`) vs. Projection Matrix Representational Power
We asked a fundamental geometric question: *Now that our projection matrices $W_{\text{in}} \in O(768)$ and $W_q, W_k, W_v \in \mathrm{St}(768, 768)$ are properly optimized on Riemannian manifolds, do we still need the initial token embedding table `wte.weight` ($50,304 \times 768$, `38.6M` parameters) to be trainable, or do the projection matrices have enough representational power on their own?*

**Mathematical Answer**:
- Look at how token embeddings $E_{\text{wte}} \in \mathbb{R}^{V \times 768}$ enter Layer 0:
  $$Q^{(0)} = E_{\text{wte}}\,W_{\text{in}}\,W_q^{(0)}, \qquad K^{(0)} = E_{\text{wte}}\,W_{\text{in}}\,W_k^{(0)}, \qquad V^{(0)} = E_{\text{wte}}\,W_{\text{in}}\,W_v^{(0)}$$
- Because $W_{\text{in}} \in O(768)$ and $W_q^{(0)}, W_k^{(0)}, W_v^{(0)} \in \mathrm{St}(768, 768)$ are orthogonal matrices ($W^\top W = I_{768}$), multiplying $E_{\text{wte}}$ on the right by $W_{\text{in}} W_q^{(0)}$ applies the **same global $768 \times 768$ orthogonal rotation** to every token in the vocabulary.
- Consequently, the $50,304 \times 50,304$ pairwise token inner-product Gram matrix is **strictly invariant** to $W_{\text{in}}, W_q^{(0)}, W_k^{(0)}, W_v^{(0)}$:
  $$\big(E_{\text{wte}} W_{\text{in}}\big)\big(E_{\text{wte}} W_{\text{in}}\big)^\top = E_{\text{wte}}\,\underbrace{W_{\text{in}} W_{\text{in}}^\top}_{=\,I_{768}}\,E_{\text{wte}}^\top = E_{\text{wte}} E_{\text{wte}}^\top$$
- If `wte.weight` is frozen at **random** unit-RMS sphere vectors (`FROZEN_RANDOM_SPHERE`), any two synonymous tokens (e.g., `"quick"` and `"fast"`) are nearly orthogonal ($\langle e_u, e_v\rangle / 768 \approx 0 \pm 1/\sqrt{768}$), and **no orthogonal matrix $W \in O(768)$ can ever bring two orthogonal token vectors closer together**! The network can only separate or cluster synonyms after non-linear contextual mixing in deeper layers.
- **However**, if we initialize and freeze `wte.weight` on $\sqrt{768}\,\mathbb{S}^{767}$ using **Shifted Positive Pointwise Mutual Information (PPMI) + Randomized SVD** ([`compute_ppmi_svd_embeddings`](file:///home/nixos/QuantumDLBlocks/src/qdlblocks/layers/cooccurrence_init.py#L22-L120), mode `FROZEN_PPMI_SVD_SPHERE`), then the $50,304 \times 50,304$ semantic similarity geometry $E_{\text{wte}} E_{\text{wte}}^\top$ is **already encoded at Step 0**, and $W_{\text{in}}, W_q, W_k, W_v$ only need to rotate those 768 principal spectral axes into the 6 quantum heads!
- **Exact `compute_ppmi_svd_embeddings` Construction (`< 5` seconds on GPU)**:
  1. Scans the first `25,000,000` tokens of training Shard 1 (`fineweb_train_000001.bin`), counting co-occurrences $\#(w, c)$ between target words $w \in \{0, \dots, 50,303\}$ and `num_context_buckets = 2048` frequent/hashed context columns $c$ within a symmetric sliding window of radius `window_size = 4` ($\pm 4$ tokens).
  2. Applies Levy-Goldberg Context-Distribution Smoothing (`cds_alpha = 0.75`, $P_\alpha(c) = \frac{\#(c)^{0.75}}{\sum_{c'}\#(c')^{0.75}}$) and Shifted PPMI (`shift_kappa = 1.0`):
     $$M_{w,c} = \operatorname{SPPMI}(w, c) = \max\!\left(0,\; \log\frac{\#(w, c)\,\sum_{c'}\#(c')^{0.75}}{\#(w)\,\#(c)^{0.75}} - \log(1.0)\right) \in \mathbb{R}^{50,304 \times 2048}$$
  3. Runs GPU Randomized SVD (`torch.svd_lowrank(M, q=800, niter=4)` with oversampling `q = 768 + 32 = 800`), forms the symmetric square-root-weighted spectral embedding $E_{\text{raw}} = U_{:,:768}\,\operatorname{diag}(\Sigma_{:768}^{1/2}) \in \mathbb{R}^{50,304 \times 768}$, replaces any zero-count rare rows with seeded normal vectors, and projects every row onto $\sqrt{768}\,\mathbb{S}^{767}$.

### 3.5. Problem 5: Comparing Quadratic, Cubic Fermi-Dirac, and Learnable-Temperature Purification
Given a contextual density matrix $\rho_0 \in \mathrm{Herm}_+(16)$ with eigenvalues $\lambda_i \in [0, 1]$ ($\sum_{i=1}^{16} \lambda_i = 1$), we compared three spectral purification maps in [`purify_density_statmech`](file:///home/nixos/QuantumDLBlocks/src/qdlblocks/layers/quantum_statmech_channels.py#L186-L200):
1. **`QUADRATIC_MCWEENY`**: $\rho^{(1)} = \frac{\rho_0^2}{\operatorname{Tr}(\rho_0^2)}$, which maps $\lambda_i \mapsto \frac{\lambda_i^2}{\sum_j \lambda_j^2}$ (`1` complex matmul).
2. **`CUBIC_FERMI_DIRAC`**: Applies the symmetric zero-temperature electronic-structure McWeeny / Fermi-Dirac polynomial $g(\lambda) = 3\lambda^2 - 2\lambda^3 = \lambda^2(3 - 2\lambda)$:
   $$\tilde{\rho} = 3\rho_0^2 - 2\rho_0^3, \qquad \rho^{(1)} = \frac{\tilde{\rho}}{\operatorname{Tr}(\tilde{\rho})}$$
   Unlike $\lambda^2$ (whose derivative at $\lambda = 1$ is $2$, unevenly stretching near-pure states), $g(\lambda) = 3\lambda^2 - 2\lambda^3$ is a true **spectral S-curve** with $g(0)=0, g(1)=1, g(1/2)=1/2$, and **zero derivative at both endpoints** ($g'(0) = g'(1) = 0$), suppressing noisy eigenvalues below $1/2$ while stabilizing dominant eigenvalues near $1$.
3. **`LEARNABLE_TEMP_MCWEENY`**: Parameterizes a per-head learnable convex combination over the unpurified state $\rho_0$ (high temperature), quadratic $\rho_{\text{quad}}$ (medium temperature), and cubic $\rho_{\text{FD}}$ (low temperature) via softmax weights $\alpha_h = \mathrm{softmax}(\theta_h) \in \Delta^2$:
   $$\rho^{(1)} = \alpha_{h,0}\,\rho_0 + \alpha_{h,1}\,\rho_{\text{quad}} + \alpha_{h,2}\,\rho_{\text{FD}}$$

### 3.6. Problem 6: Why the Detached Purity / Tsallis-2 Entropy Gate Is Appealing
In quantum statistical mechanics, the **Tsallis-2 linear entropy** of a density matrix $\rho$ is $S_2(\rho) = 1 - \operatorname{Tr}(\rho^2) = 1 - \mathcal{P}(\rho) \in [0, 1 - \frac{1}{16}]$.
- **Why this is physically appealing for a transformer**:
  1. When head $h$ at token $t$ attends sharply to a single unambiguous antecedent token, $\rho_{t,\text{out}}$ is nearly a pure rank-1 state ($\mathcal{P} \to 1, S_2 \to 0$). In this coherent regime, the linear wavepacket pathway (`psi_u_flat`) carries clean phase information without interference cancellation.
  2. Conversely, when head $h$ aggregates over many distinct context tokens (high contextual ambiguity), the linear wavepacket sum $\sum_{s \le t} w_{t,s} |\psi_s\rangle$ suffers destructive phase cancellation, whereas the quadratic density matrix $\rho_{t,\text{out}}$ and its rank-2 Krylov eigenmodes (`packed_rho_out`, `krylov_64`) faithfully preserve the multi-modal mixture ($\mathcal{P}$ low, Tsallis-2 entropy $S_2$ high).
  3. Thus, purity $\mathcal{P}$ and Tsallis-2 entropy $S_2 = 1 - \mathcal{P}$ provide an **intrinsic, zero-cost physical measure of head certainty** that is already computed inside every block!
- **Why `.detach()` is mandatory ([`apply_detached_tsallis_entropy_gate`](file:///home/nixos/QuantumDLBlocks/src/qdlblocks/layers/quantum_statmech_channels.py#L521-L557))**:
  As we discovered in Wave 48 (`Fix 2`), if any scalar gate multiplying the head output differentiates through $\operatorname{Tr}(\rho^2)$, backpropagation immediately rewards $W_v$ for collapsing all tokens to a single constant rank-1 vector so $\operatorname{Tr}(\rho^2) \to 1$. By using **detached purity** $\mathcal{P}_{\text{det}} = \operatorname{Tr}(\rho^2).\text{detach}()$ centered at $\mathcal{P}_0 = 0.35$ ($\Delta\mathcal{P} = \mathcal{P}_{\text{det}} - 0.35$, $\Delta S_2 = -\Delta\mathcal{P}$), the gate learns three per-head routing slopes $(s_{\text{coh},h}, s_{\text{mix},h}, s_{\text{conf},h})$:
  $$w_{\text{coh}} = \sqrt{2}\,\sigma(s_{\text{coh},h}\,\Delta\mathcal{P}), \qquad w_{\text{mix}} = \sqrt{2}\,\sigma(s_{\text{mix},h}\,\Delta S_2), \qquad w_{\text{conf}} = \mathrm{clamp}\big(1 + 0.5\tanh(s_{\text{conf},h})\,\Delta\mathcal{P},\; 0.5,\; 1.5\big)$$
  routing coherent vs. mixed states and scaling head confidence with **zero radial purity-collapse gradient**.

### 3.7. Problem 7: Off-Manifold Euclidean Momentum Accumulation & Full-Network Geometric Update Restrictions

#### 3.7.1. The Slowdown Observation & Hypothesis
During our long scaling run of the rebuilt `Wave 48 v3` architecture (`w49_v3_rebuilt_600m`), validation cross-entropy dropped rapidly from `11.2914` (`0M` tokens) to `5.0502` (`50M` tokens) and `4.6325` (`100M` tokens), but between `100M` and `200M` tokens (`step 12,207` to `step 24,414`) reduced by only `-0.1122` nats (`4.5203` at `200M` tokens, `4.5133` at `204.8M` tokens).

We hypothesized that this slowdown was caused by **accumulating Euclidean momentum in the ambient space $\mathbb{R}^{D \times d}$ before projecting onto the Stiefel tangent space**.

#### 3.7.2. Mathematical & Diagnostic Proof of Normal-to-Tangent Momentum Leakage
At any point $W \in \mathrm{St}(D, d)$ ($D \ge d$, $W^\top W = I_d$), the ambient space $\mathbb{R}^{D \times d}$ decomposes into three mutually orthogonal subspaces under the Frobenius inner product $\langle A, B\rangle_F = \operatorname{Tr}(A^\top B)$:
$$\mathbb{R}^{D \times d} = \underbrace{\mathcal{H}_W\mathrm{St}(D, d)}_{\text{Horizontal Tangent } (I_D - WW^\top)V} \oplus \underbrace{\mathcal{V}_W\mathrm{St}(D, d)}_{\text{Vertical Lie-Algebra Tangent } W\,\mathrm{skew}(W^\top V)} \oplus \underbrace{N_W\mathrm{St}(D, d)}_{\text{Symmetric Normal } W\,\mathrm{sym}(W^\top V)}$$
where $\mathrm{sym}(M) = \frac{1}{2}(M + M^\top)$ and $\mathrm{skew}(M) = \frac{1}{2}(M - M^\top)$, and the full canonical Stiefel tangent space is $T_W\mathrm{St}(D, d) = \mathcal{H}_W \oplus \mathcal{V}_W = \{V \in \mathbb{R}^{D \times d} : W^\top V + V^\top W = 0\}$, with orthogonal projection:
$$\mathcal{P}_{T_W\mathrm{St}(D, d)}(V) = V - W\,\mathrm{sym}(W^\top V) = V - \frac{1}{2}W(W^\top V + V^\top W)$$

We built [`compute_real_stiefel_vector_diagnostics`](file:///home/nixos/QuantumDLBlocks/src/qdlblocks/layers/quantum_statmech_channels.py#L302-L385) to measure the exact geometry of the raw gradient $G_t$, pre-step momentum $M_{t-1}$, updated momentum $M_t$, Newton-Schulz tangent velocity $U_{\text{tan},t}$, and retracted weight $W_{t+1}$, and uncovered **four critical geometric flaws** in the prior optimizer:

1. **Flaw A — `70%–78%` Off-Manifold Normal Gradient Accumulation & Curvature Leakage (`EUCLIDEAN_AMBIENT`)**:
   - In our `200M`-token checkpoint diagnostic, **`69.1%` to `77.6%` of the raw Euclidean gradient norm** $\|G_{\text{norm}}\|_F / \|G\|_F$ points orthogonally off the Stiefel manifold (and **`74.5%`** on the complex $U(16)$ operators).
   - Under `EUCLIDEAN_AMBIENT` ($M_t = \beta M_{t-1} + G_t$), that normal component is stored in `momentum_buffer` (`pre_mom_normal_frac = 0.775`). When $W_t$ moves to $W_{t+1} \approx W_t - \eta U_{\text{tan}}$, yesterday's normal component $M_{\text{norm}}(W_t) = W_t\,\mathrm{sym}(W_t^\top M_t)$ has a non-zero projection onto the **new** tangent space $T_{W_{t+1}}\mathrm{St}(D, d)$:
     $$\mathcal{P}_{T_{W_{t+1}}}\!\big(M_{\text{norm}}(W_t)\big) = -\eta\,(I_D - W_t W_t^\top)\,U_{\text{tan}}\,\mathrm{sym}(W_t^\top M_t) + O(\eta^2) \neq 0$$
     Measured empirically (`normal_to_tangent_leakage_ratio`), this off-manifold momentum leaks into the tangent search direction every step and degrades cosine alignment between the tangent gradient and tangent momentum (`cos(g_tan, m_tan)` drops from `0.629` to `0.506`).
2. **Flaw B — Discarding `14.14M` Vertical Skew-Symmetric Stiefel Tangent DOFs (`28.31M` Matrix Entries) on the `48` Rectangular Stiefel Matrices**:
   - Previously, in [`_stiefel_muon_SingleStep`](file:///home/nixos/QuantumDLBlocks/src/qdlblocks/models/standalone_quantum_born_gpt.py#L446-L452), while the `37` square orthogonal matrices (`rows == cols == 768`) used the skew-symmetric tangent formula $\frac{1}{2}(V - W V^\top W)$, all **`48` rectangular Stiefel matrices** (`w_obs` $\in \mathrm{St}(1920, 768)$ and `w_beam_a, w_beam_b, w_chan` $\in \mathrm{St}(1536, 768)$ across 12 layers, after transposing wide matrices so `rows > cols`) took the `rows > cols` branch $V - W(W^\top V)$. That horizontal Grassmann projection projects out **both** the normal part $W\,\mathrm{sym}(W^\top V)$ **and** the vertical skew-symmetric tangent part $W\,\mathrm{skew}(W^\top V) \in T_W\mathrm{St}(D, d)$—zeroing out $48 \times \frac{768 \times 767}{2} = \mathbf{14,137,344}$ (`14.14M`) internal column-rotation degrees of freedom ($48 \times 768^2 = \mathbf{28,311,552}$ matrix entries in $W\,\mathrm{skew}(W^\top V)$)!
   - Because the columns of `w_obs`, `w_beam_a`, `w_beam_b`, and `w_chan` are paired coordinate-wise in the Mach-Zehnder interferometer or mapped directly to residual features, our loss is **not** Grassmann right-$O(d)$ invariant: rotating columns *within* $\mathrm{span}(W)$ ($W\,\mathrm{skew}(W^\top V)$) is how the interferometer aligns beams! Our diagnostic revealed that `grad_skew_tangent_frac = 0.6873` (**`68.73%` of the total gradient norm!**) lives in $W\,\mathrm{skew}(W^\top G)$. Using the unified canonical Stiefel tangent projection $\mathcal{P}_{T_W\mathrm{St}(D,d)}(V) = V - \frac{1}{2}W(W^\top V + V^\top W)$ for **all `85` square and rectangular Stiefel matrices** preserves all `14.14M` internal column-rotation DOFs while still guaranteeing $(W - \eta U_{\text{tan}})^\top(W - \eta U_{\text{tan}}) = I_d + \eta^2 U_{\text{tan}}^\top U_{\text{tan}}$ because $W^\top U_{\text{tan}} + U_{\text{tan}}^\top W = 0$.
3. **Flaw C — Double-Step Stale-Gradient Corruption on `lm_head.weight` ($\sqrt{d}\,\mathbb{S}^{d-1}$)**:
   - In [`StandaloneRiemannianOptimizerBundle.step`](file:///home/nixos/QuantumDLBlocks/src/qdlblocks/models/standalone_quantum_born_gpt.py#L909), `head_opt` previously called `step_active(act_ids, lr_scale * 0.75)` followed immediately by `step_full(lr_scale * 0.25)` on the **same** `lm_head.weight.grad`. Because `step_active` had already retracted the active vocabulary rows `lm_head.weight[act_ids]` to a new point $W_{\text{mid}}$ and updated `mom_buf[act_ids]`, the subsequent `step_full` projected the stale gradient $\nabla_{W_{\text{old}}}\mathcal{L}$ onto the new tangent space $T_{W_{\text{mid}}}\mathbb{S}^{767}$, leaking radial normal components into the tangent space and double-accumulating `mom_buf` and `exp_avg_sq` for active tokens.
   - We fixed [`BatchSubspaceTikhonovGramMuon.step_full`](file:///home/nixos/QuantumDLBlocks/src/qdlblocks/optim/vocab_manifold_muon.py#L195-L266) to accept `active_idx`, executing a single unified update per step.
4. **Flaw D — Ambient Gradient Clipping & Unconstrained 1D Scalar Drift**:
   - Standard `torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)` includes the `70%+` normal gradient components that are immediately discarded by tangent projection, throttling tangent updates whenever a radial gradient spikes. We implemented [`clip_riemannian_tangent_grad_norm_`](file:///home/nixos/QuantumDLBlocks/src/qdlblocks/models/modular_quantum_statmech_gpt.py#L662-L700) to clip strictly by the intrinsic Riemannian tangent norm across all Stiefel, Unitary, and Sphere manifolds, and [`restrict_scalar_parameters_`](file:///home/nixos/QuantumDLBlocks/src/qdlblocks/models/modular_quantum_statmech_gpt.py#L644-L660) to clamp 1D scalar gains and highway weights to bounded physical intervals after each AdamW step.

$$\text{lr\_mult}(t) = 0.15 + \frac{0.85}{2}\Big(1 + \cos\big(\pi\,\min(1, t / T_{\text{sched}})\big)\Big)$$
clip all parameter gradients by their intrinsic Riemannian tangent norm (`max_norm = 1.0`), and update all four parameter families in [`ModularRiemannianStiefelKrausMuon`](file:///home/nixos/QuantumDLBlocks/src/qdlblocks/models/modular_quantum_statmech_gpt.py#L703-L814):

To make every table below completely self-contained, here are the exact mathematical definitions of our telemetry metrics:
- **Quantum State Purity & Effective Rank**:
  - `mean_purity`: $\frac{1}{L H B T}\sum_{\ell=0}^{11}\sum_{h=1}^6\sum_{b,t} \operatorname{Tr}\!\big((\rho_{b,t,h,\text{out}}^{(\ell)})^2\big) \in [\frac{1}{16}, 1] = [0.0625, 1.0]$.
  - `mean_eff_rank` (`eff_rank`): $\frac{1}{L H B T}\sum_{\ell,h,b,t} \frac{1}{\operatorname{Tr}((\rho_{b,t,h,\text{out}}^{(\ell)})^2)} \in [1, 16]$, the inverse participation ratio (number of active quantum eigenmodes per head).
- **Manifold Preservation Errors**:
  - `mean_stiefel_err` / `max_stiefel_err`: Mean and maximum across all `85` real Stiefel matrices $W \in \mathrm{St}(D, d)$ of the column-orthonormality residual $\frac{\|W^\top W - I_d\|_F}{\sqrt{d}}$.
  - `mean_unitary_err` / `max_unitary_err`: Mean and maximum across all `12` layers of $\frac{1}{H}\sum_{h=1}^H \frac{\|A_h^\dagger A_h - I_{16}\|_F}{\sqrt{16}}$ ($A_h \in U(16)$ or $\mathrm{St}_{\mathbb{C}}(64, 16)$).
- **Riemannian Vector-Transport & Subspace Decomposition Diagnostics ([`compute_real_stiefel_vector_diagnostics`](file:///home/nixos/QuantumDLBlocks/src/qdlblocks/layers/quantum_statmech_channels.py#L302-L385), averaged across all `85` real Stiefel matrices or `12` complex Unitary/Kraus tensors)**:
  - `grad_normal_frac`: $\frac{\|W\,\mathrm{sym}(W^\top G_t)\|_F}{\|G_t\|_F}$, the fraction of raw gradient norm pointing orthogonally off the Stiefel manifold into $N_W\mathrm{St}(D, d)$.
  - `grad_skew_tangent_frac`: $\frac{\|W\,\mathrm{skew}(W^\top G_t)\|_F}{\|G_t\|_F}$, the vertical Lie-algebra tangent fraction (rotating columns within $\mathrm{span}(W)$).
  - `grad_horiz_tangent_frac`: $\frac{\|(I_D - W W^\top)G_t\|_F}{\|G_t\|_F}$, the horizontal Grassmann tangent fraction (moving $\mathrm{span}(W)$ into $\mathrm{span}(W)^\perp$). By Pythagoras, $\text{grad\_horiz\_tangent\_frac}^2 + \text{grad\_skew\_tangent\_frac}^2 + \text{grad\_normal\_frac}^2 = 1$.
  - `pre_mom_normal_frac`: $\frac{\|W_t\,\mathrm{sym}(W_t^\top M_{t-1})\|_F}{\|M_{t-1}\|_F}$, how much of the stored momentum buffer $M_{t-1}$ has drifted off-manifold prior to step $t$.
  - `post_mom_normal_at_w_next_frac`: $\frac{\|W_{t+1}\,\mathrm{sym}(W_{t+1}^\top M_{\text{stored}})\|_F}{\|M_{\text{stored}}\|_F}$, the off-manifold normal fraction of the newly stored momentum at the retracted point $W_{t+1}$.
  - `normal_to_tangent_leakage_ratio`: $\frac{\|\mathcal{P}_{T_{W_{t+1}}}(W_t\,\mathrm{sym}(W_t^\top M_t))\|_F}{\|\mathcal{P}_{T_{W_{t+1}}}(M_t)\|_F}$, measuring the curvature-induced leakage of step $t$'s normal momentum component into step $t+1$'s tangent space $T_{W_{t+1}}\mathrm{St}(D, d)$.
  - `cos(g_tan, m_tan)`: $\frac{\langle \mathcal{P}_{T_W}(G_t),\, \mathcal{P}_{T_W}(M_t)\rangle_F}{\|\mathcal{P}_{T_W}(G_t)\|_F\,\|\mathcal{P}_{T_W}(M_t)\|_F}$, directional alignment between the instantaneous tangent gradient and tangent momentum.

1. **$32\times$ Smaller Effective Batch Size (`8,192` vs. `262,144` Tokens/Step)**:
   - `CompiledLeaderboardClassicalGPT` trains at `262,144` tokens per optimizer step (`grad_accum` across `32` micro-batches of `8,192` tokens).
   - Every standalone quantum run in Waves 48–49 used `8,192` tokens per step (`B=8, T=1024, grad_accum=1`). On Riemannian manifolds—especially in `BatchSubspaceTikhonovGramMuon` where the $768 \times 768$ feature Gram matrix $\Gamma = M_{\text{tan}}^\top M_{\text{tan}}$ and token SNR gates are estimated from active batch tokens, and in `ModularRiemannianStiefelKrausMuon` where Newton-Schulz orthogonalization amplifies noisy singular directions of small-batch gradients—taking `18,311` high-variance `8k`-token steps instead of `~572` low-variance `262k`-token steps introduces severe stochastic gradient noise.
2. **Cold-Start Token Embedding Geometry (`wte`)**:
   - In our `4.10M`-token ablation (Section 4.1), simply initializing `wte.weight` with **Shifted-PPMI + Randomized SVD** (`FROZEN_PPMI_SVD_SPHERE`) reduced validation loss by **`-0.2382` nats (`5.9069` vs. `6.1451`)** at `4.10M` tokens. In contrast, both `150M`-token runs started `wte.weight` from random Gaussian vectors on $\sqrt{768}\,\mathbb{S}^{767}$, spending tens of millions of tokens slowly rotating `50,304` vocabulary rows (`~1,800` active tokens per batch) into semantic alignment.
3. **Omission of Modded-NanoGPT Macro-Architectural Accelerators**:
   - As proven in Wave 48's Layer 11 swap benchmark (where a single quantum Born layer swapped into `CompiledLeaderboardClassicalGPT` beat classical `SDPA` softmax: `3.7517` vs. `3.7660` Val CE), the quantum attention mechanism itself is *not* inferior to classical `SDPA` when placed inside the same macro-architecture!
   - Rather, `CompiledLeaderboardClassicalGPT` benefits from three token `value_embeds` banks (`115.9M` direct-lookup parameters injected into layers), U-Net encoder-decoder skip connections (`Layers 0..5 -> 11..6`), and `SmearGate` bigram mixing, which dramatically accelerate early token efficiency in the first `50M–100M` tokens.

### 5.2. Deep-Dive Question for Next Session: Why Does `69%–78%` of the Gradient Magnitude Point Outside the Tangent Plane, and What Can We Do About It?

One of the most striking empirical findings from our vector-transport diagnostic (`Section 4.3` & `Section 4.4`) is that even after we completely eliminated off-manifold momentum accumulation (`pre_mom_normal_frac = 5.8e-7`), **`69.15%` to `77.62%` of the raw backpropagation gradient norm on the real Stiefel matrices (`grad_normal_frac`) and `74.40%` on the complex $U(16)$ operators (`unitary_grad_normal_frac`) points orthogonally outside the tangent plane**—into the symmetric normal space $N_W\mathrm{St}(D, d) = \{W\,\mathrm{sym}(W^\top G)\}$—and has to be thrown away at every step!

Why is the loss function expending `~70%–78%` of its gradient magnitude (`~48%–60%` of its squared gradient energy) pushing orthogonal to the manifold constraint, and what can we do about it in the next session?

#### 1. Three Linear-Algebraic & Physical Clarifications on the Normal Gradient $W\,\mathrm{sym}(W^\top G)$
1. **Pythagorean Three-Subspace Norm vs. Squared-Energy Identity**:
   - Because $\mathcal{H}_W = \{(I_D - W W^\top)G\}$, $\mathcal{V}_W = \{W\,\mathrm{skew}(W^\top G)\}$, and $N_W = \{W\,\mathrm{sym}(W^\top G)\}$ are mutually orthogonal under the Frobenius inner product, their **squared** norm fractions sum to `1.0`:
     $$\underbrace{\text{grad\_horiz\_tangent\_frac}^2}_{0.2223^2\,=\,4.94\%} + \underbrace{\text{grad\_skew\_tangent\_frac}^2}_{0.6873^2\,=\,47.24\%} + \underbrace{\text{grad\_normal\_frac}^2}_{0.6915^2\,=\,47.82\%} = 1.0000$$
     Thus, at `150M` tokens (`Table 4.4c`), `69.15%` normal norm and `68.73%` vertical skew-tangent norm coexist because they represent `47.82%` and `47.24%` of the **squared** gradient energy $\|G\|_F^2$ (`52.18%` total tangent energy vs. `47.82%` normal energy; rising at `200M` tokens to $0.7762^2 = \mathbf{60.25\%}$ normal squared energy vs. $39.75\%$ tangent squared energy).
2. **Dimensional Equipartition Baseline on Square $O(768)$ and $U(16)$ vs. Rectangular $\mathrm{St}(D, d)$**:
   - What would `grad_normal_frac` be for a completely isotropic random Gaussian matrix $G \sim \mathcal{N}(0, I)$?
   - On the **`37` square orthogonal matrices** ($D = d = 768$: `w_in_stiefel`, `w_q`, `w_k`, `w_v`), the horizontal complement $I_D - W W^\top = 0$ vanishes (`grad_horiz_tangent_frac = 0`), the skew-symmetric tangent space has dimension $\dim \mathrm{skew}(d) = \frac{d(d-1)}{2} = 294,528$, and the symmetric normal space has dimension $\dim \mathrm{sym}(d) = \frac{d(d+1)}{2} = 295,296$. Thus, an isotropic random gradient on $O(768)$ **already has an expected normal norm fraction of $\sqrt{\frac{d+1}{2d}} \approx \frac{1}{\sqrt{2}} \approx \mathbf{70.76\%}$** (`50.07%` of squared energy)! Similarly, on $U(16) \subset \mathbb{C}^{16 \times 16}$, both the skew-Hermitian tangent space and Hermitian normal space have real dimension $16^2 = 256$, giving an isotropic baseline of $\frac{1}{\sqrt{2}} = \mathbf{70.71\%}$.
   - In contrast, on the **`48` rectangular Stiefel matrices** ($D \in \{1536, 1920\}, d = 768$), the ambient dimension is $D d$ while $\dim N_W = \frac{d(d+1)}{2}$, so an isotropic random gradient in $\mathbb{R}^{D \times d}$ would have an expected normal norm fraction of only $\sqrt{\frac{d+1}{2D}} \approx \mathbf{44.7\%\text{–}50.0\%}$ (`20%–25%` of squared energy) and horizontal tangent norm $\sqrt{1 - \frac{d}{D}} \approx \mathbf{70.7\%\text{–}77.5\%}$. The fact that our network-wide average `grad_horiz_tangent_frac` drops to `0.2223` (`4.94%` of squared energy) while `grad_normal_frac` reaches `0.6915–0.7762` (and `unitary_grad_normal_frac` reaches `0.7440–0.8390`, well above `0.7071`) proves that the loss gradient is **strongly concentrated inside $\mathrm{span}(W)$** (`~95%` of squared energy lies in $\mathcal{V}_W \oplus N_W$) and experiences genuine singular-value and metric-shear pressure beyond isotropic noise.
3. **Diagonal vs. Off-Diagonal Normal Forces & What Per-Token `RMSNorm` Actually Removes**:
   - For a contraction or square projection $Y = X W$ ($X \in \mathbb{R}^{N \times D}, W \in \mathrm{St}(D, d)$), $W^\top G = Y^\top \nabla_Y \mathcal{L} \in \mathbb{R}^{d \times d}$ (while for the transposed expansion matrices `w_beam_a, w_beam_b` where $Y = X W_{\text{tall}}^\top$, $W_{\text{tall}}^\top G_{\text{tall}} = ((\nabla_Y \mathcal{L})W_{\text{tall}})^\top X \in \mathbb{R}^{d \times d}$ measures input-space alignment).
   - Decomposing $\mathrm{sym}(W^\top G)$ into its **$d$ diagonal entries** and **$\frac{d(d-1)}{2}$ off-diagonal symmetric entries** separates two physical effects:
     - **Diagonal Normal Gradient ($\operatorname{diag}(W^\top G)_j = (Y^\top \nabla_Y \mathcal{L})_{j,j}$) — Relative Singular-Value / Channel-Scale Pressure**: Wants to stretch or shrink individual column singular values $\sigma_j$ away from $1$.
     - **Off-Diagonal Symmetric Normal Gradient ($\frac{1}{2}((W^\top G)_{i,j} + (W^\top G)_{j,i})$ for $i \neq j$) — Inter-Column Shear / Metric Pressure**: Wants columns $W_{:,i}$ and $W_{:,j}$ to become non-orthogonal ($\langle W_{:,i}, W_{:,j}\rangle \neq 0$).
   - **Crucial subtlety about per-token `RMSNorm(Y)`**: When an output row $y_n \in \mathbb{R}^d$ passes through per-token $z_n = \mathrm{RMSNorm}(y_n)$, the radial orthogonality identity $\langle y_n, (\nabla_Y \mathcal{L})_n\rangle = \sum_{j=1}^d y_{n,j}(\nabla_Y \mathcal{L})_{n,j} = 0$ holds **summed across all $d$ channels**, which only zeroes the **1D scalar trace** $\operatorname{Tr}(W^\top G) = \sum_{j=1}^d (Y^\top \nabla_Y \mathcal{L})_{j,j} = 0$! It does **not** zero the $d-1$ **traceless diagonal normal gradients** $(Y^\top \nabla_Y \mathcal{L})_{j,j} \neq 0$ (which want to re-weight feature channel $j$ relative to channel $k$) or the $\frac{d(d-1)}{2}$ off-diagonal symmetric normal gradients!

#### 2. Four Concrete Architectural & Mathematical Remedies to Test Next Session
1. **Per-Matrix Diagnostic Breakdown (`horiz`, `skew`, `trace_normal`, `traceless_diag_normal`, `offdiag_sym_normal`)**:

2. **Eliminate Unnormalized Linear Pathways That Inject Isotropic & Per-Head Radial Scale Gradients Into $W$**:
   - Auditing `ModularQuantumStatMechBlock` reveals two specific pathways where even the per-token/per-head radial trace is not normalized before entering scale-sensitive operations:
     - **Unnormalized `v_branch_flat` in Causal Born Attention**: In `compute_quantum_attention_features`, `packed_tok_288` normalizes each token's density matrix ($\operatorname{Tr}(\rho_s^{\text{tok}}) = 1$) and mean ket ($\||\hat{v}_s^{\text{coh}}\rangle\|_2 = 1$), but concatenates the **raw unnormalized** `v_branch_flat` (`128` dims/head) into `attn_weights @ cat([packed_tok_288, v_branch_flat])`! Because `v_branch_flat` is only normalized *after* causal attention aggregation, tokens $s$ with larger $\|v_{\text{mixed},s,h}\|_2$ disproportionately weight the linear wavepacket sum $\sum_{s \le t} w_{t,s}|\psi_{s,r}\rangle$, creating a direct radial scale gradient on `w_v`!      - **Quadratic Scale Sensitivity in Mach-Zehnder Beams (`w_beam_a`, `w_beam_b`)**: Because $\mathrm{ReLU}(\frac{a+b}{\sqrt{2}})^2 - \frac{1}{4}\mathrm{ReLU}(\frac{a-b}{\sqrt{2}})^2$ is homogeneous of degree 2 in the beam amplitudes $(a_i, b_i)$, any desire by the loss to re-weight feature $i$ relative to feature $j$ generates twice the diagonal normal gradient on the rows of `w_beam_a, w_beam_b`.
3. **Channel-Scaled Stiefel Parameterization ($A = W\,\operatorname{diag}(s)$ with $W \in \mathrm{St}(D, d), s \in \sqrt{d}\,\mathbb{S}^{d-1}$) & Factored Head-Metric**:
   - Instead of discarding the $(d-1)$-dimensional traceless diagonal normal gradient $\operatorname{diag}(W^\top G)$, factor linear maps as $A = W\,\operatorname{diag}(s)$ where $W \in \mathrm{St}(D, d)$ is updated on the Stiefel manifold by $\mathcal{P}_{T_W}(G)$ and a learnable singular-value vector $s \in \sqrt{d}\,\mathbb{S}^{d-1}$ (initialized to $\mathbf{1}_d$, adding only `768` parameters per matrix) absorbs the traceless diagonal normal gradient $\operatorname{diag}(W^\top G) - \frac{1}{d}\operatorname{Tr}(W^\top G)\mathbf{1}_d$! This converts wasted diagonal normal gradient energy into productive per-channel singular-value adaptation while preserving exact column orthogonality $W^\top W = I_d$ and unit mean singular value.
4. **Isometric Frame Conditioning (Pre-Whitening Input Activation Covariance $\Sigma_X = \frac{1}{N}X^\top X$)**:
   - Whenever the input activation covariance $\Sigma_X = \frac{1}{N}X^\top X$ is anisotropic along $\mathrm{span}(W)$, the Euclidean gradient $G = X^\top \nabla_Y \mathcal{L}$ is stretched along the dominant eigenvectors of $\Sigma_X$, rotating tangent directions into off-diagonal symmetric normal directions $\mathrm{sym}_{\text{off}}(W^\top G)$. Preconditioning Stiefel updates with a damped feature-covariance inverse square root (analogous to `BatchSubspaceTikhonovGramMuon`) aligns the Euclidean gradient with the canonical Stiefel metric.
